# Парсер книг Books to Scrape

Проект собирает данные о книгах с учебного сайта
[Books to Scrape](https://books.toscrape.com/).

Для каждой книги собираются название, цена, рейтинг, количество в наличии,
описание и характеристики из таблицы Product Information.

## Используемые библиотеки

- `requests` — получение страниц сайта;
- `beautifulsoup4` — поиск данных в HTML;
- `schedule` — запуск сбора по расписанию;
- `pytest` — запуск тестов.

## Установка

В терминале из папки проекта создайте и активируйте виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

Команда активации выше предназначена для macOS и Linux.

## Сбор данных

В файле `scraper.py` находятся функции:

- `get_book_data(book_url)` — собирает данные одной книги;
- `scrape_books(is_save=True)` — собирает данные каталога и сохраняет их в
  файл `books_data.txt` в текущей рабочей папке.

Пример запуска полного сбора из терминала в папке проекта:

```bash
python -c "from scraper import scrape_books; scrape_books(is_save=True)"
```

Сбор может занять несколько минут: для каждой книги отправляется отдельный запрос.

Пример сохранённого результата находится в папке `artifacts/`.

## Тесты

Запуск тестов из папки проекта:

```bash
python -m pytest tests/test_scraper.py -v
```

Тесты обращаются к сайту, поэтому для их выполнения нужен интернет.
